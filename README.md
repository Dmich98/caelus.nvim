# Caelus.nvim

A dark Neovim colorscheme based on the original [Caelus](https://git.symlinx.net/daccfiles/tree/.config/nvim-raw/lua/caelus) by **dacctal**.

This is an independently maintained fork with extended Tree-sitter, LSP semantic highlighting, and additional plugin integrations.

## Installation

Using Neovim's built-in `vim.pack`:

```lua
vim.pack.add({
  { src = "https://github.com/Dmich98/caelus.nvim" },
})

vim.cmd.colorscheme("caelus")
```
